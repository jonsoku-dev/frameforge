# saas-launch: Solotack 런치 스팟

**목적.** 할 일에 묻힌 사람에게 "하나만 고정하면 끝낼 수 있다"는 느낌을 30초 안에 남긴다.

**브랜드.** "Solotack"은 이 샘플을 위해 지어낸 가상의 작업관리 SaaS다. 실제 회사, 제품, 로고와 관계없다. 화면에 숫자와 수치 주장은 없다.

## 형식

1920×1080, 30fps, 900프레임(30초). 컴포지션 ID `SaasLaunch`. 개발 서버 포트 4401.

## 색과 글꼴

| 역할 | 값 |
| --- | --- |
| 배경 A, 글자 | ink `#0B1220` |
| 배경 B, 카드 | paper `#F6F7FB` |
| 강조(핀) | accent `#FF5A36` |
| 보조 선, ink 위 보조 글자 | muted `#C7CBD6` |
| 헤드라인 | Space Grotesk 700 |
| UI 라벨 | Inter 500 |

화면 글자는 영어다. 두 글꼴 모두 한글 글리프가 없어서다.

## 소리

- 스펙 `audio.json`: upbeat, 120 bpm, C major, seed 10. 구간 problem 0-5s (0.25), pin 5-8.3s (0.5), cards 8.3-22s (0.85), promise 22-28s (0.5), hold 28-30s (0.1). 히트 5, 22초.
- 음악 `/audio/generated/saas-launch/music.wav` 루트, volume 0.9. 효과음은 `/audio/generated/saas-launch/<이름>.wav` volume 0.8: 프레임 whoosh.wav 150; click.wav 266, 404, 542.

## 참고와 이유

- `docs/references/opus-5-5/aiidelist.md`: 한 장면 한 가지 일, 이미 보이던 물체에서 다음 장면, 헤드라인 1.2초, 전환 가족 두세 개.
- `docs/references/opus-5-5/README.md`: 2–4초마다 화면의 일이 바뀐다, 디스플레이 하나 UI 하나, 강조색 하나.
- `examples/samples/cafe-morning/Spot.tsx`: `span`, `pop`, `push`, `Glyphs` 패턴과 원형 와이프로 배경을 바꾸는 방식.
