# 바람결 FC 시즌 리캡 (video-collage)

**목적.** 가상의 동호회 시즌 리캡 20초. 실제 영상 프레임과 모션 그래픽을 섞어 보여 준다.

**형식.** 1920×1080, 30fps, 600프레임. 컴포지션 `VideoCollage`. 브랜드 "바람결 FC"는 가상이며 실제 단체와 무관하다. 모든 수치는 "예시 · 샘플 데이터"로 표기한다.

**색.** 잉크 `#052E16`, 종이 `#F0FDF4`, 강조 `#22C55E`, 연한 `#BBF7D0`. 금지: `#06C755`.

**글꼴.** 헤드라인 Jua(400), UI Gowun Dodum(400). 금지: Gothic A1. 이 작품의 글꼴은 직접 골랐다.

**에셋.** 영상 세 개와 GIF 하나는 ffmpeg로 만든 테스트 영상이다. `public/footage/club-a.mp4`(testsrc2, 330 Hz 소리), `public/footage/club-b.mp4`(mandelbrot, 440 Hz 소리), `public/footage/badge.gif`(testsrc 240px, 2초). 원본 파일은 실제 촬영물이 아니다.

## 소리

- 음악: `audio.json`, 120 BPM, upbeat, 타격 3 s와 15 s. 구간은 0–3, 3–9, 9–15, 15–18, 18–20. 마지막 2 s의 에너지는 0.1.
- 영상 A와 B의 자체 소리는 음량 0.4로 음악 아래에 둔다.
- 효과음 세 개(pop, whoosh, ding)는 `MotionSound`가 움직임에서 뽑는다. 타격 프레임 90과 450은 `quiet`로 비웠다.
- 손으로 둔 `<Sequence><Audio/>`는 없다. 점수 카운트 끝은 움직임이 없는 사건이라 효과음을 넣지 않았다.

## 금지

- 장면 사이 검정과 흰색 직접 컷 없음. 제목은 잉크에서 잉크로 이어진다.
- 가짜 베젤, 프레임 테두리, 글로우, 입자 없음. 강조색 판은 영상 뒤의 그림자 역할만 한다.
- 실제 로고, 실제 수치, 실제 단체명 없음.
- 마지막 2 s(540 이후)는 움직임 없음. 배지 GIF는 540 프레임에서 사라진다.
