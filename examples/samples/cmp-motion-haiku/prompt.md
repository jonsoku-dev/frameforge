# 모아담 15초 스팟 (cmp-motion-haiku)

목적: 이십대가 "매달 조금씩, 자동으로 모인다"는 한 문장과 앱 이름 "모아담"을 기억하게 한다.

가상 브랜드: 모아담. 실제 회사, 제품, 로고와 무관한 가상 이름이다. 화면의 숫자는 "예시"로 표기한다.

## 형식

- 1920×1080, 30fps, 450프레임(15초). 컴포지션 ID `CmpMotionHaiku`, 포트 4445.
- 소리 있음. `audio.json` (mood upbeat, 118 BPM, C major, 음악은 루트 1개, 효과음 whoosh/click/impact).

## 색 (4개 이하)

- 잉크 `#111827` (글자, 배경 한 면)
- 종이 `#F9FAFB` (배경, 밝은 글자)
- 강조 `#22C55E` (원, 막대, 약속 장면 배경)
- 소프트 `#DCFCE7` (단계 카드 배경)

## 글꼴

- 헤드라인: Black Han Sans 400 (`Glyphs` 글자 올리기).
- UI: Noto Sans KR 500 (라벨, 부제).
- 제외: Gothic A1, #06C755.

"화면을 채우는 것"이 "배경"만인 행은 없다. 각 행에 원판, 원반 기둥, 카드, 강조색 바탕, 이름 바탕 중 하나가 크게 있다.

## 소리

- 루트에 `/audio/generated/cmp-motion-haiku/music.wav` 볼륨 0.9.
- whoosh: 75 (전환 시작), 172 (종이색 와이프), 284 (강조색 와이프).
- click: 188, 204, 220 (카드 등장).
- impact: 390 (이름 등장). `hits`는 2.5초와 13.0초.
- 마지막 2초(13–15)는 음악 에너지 0.1로 낮춘다.

## 참고

- `examples/samples/cafe-morning/Spot.tsx`와 `examples/samples/_template/Spot.tsx`: `Glyphs` 글자 올리기, `span`, `pop`, `push`, `Sequence` 효과음 배치. 헬퍼를 그대로 복사했다.
- `docs/guides/motion-graphics.md` 4절: 연속성 규칙. 원판에서 기둥, 기둥에서 카드, 카드에서 강조색 바탕으로 이어지게 했다.
- 가족 셋: 스프링(원판, 원반, 카드), 와이프(원형 clip-path 세 번), 글자 올리기. 카메라 푸시는 한 번.

## 금지

- Math.random, Date, state, effect, CSS transition/animation.
- 글로우, 먼지 입자, 프레임 테두리, 휴대폰 베젤, 얼굴, 보석, 실제 로고.
- 헤드라인 108px 미만, 라벨 38px 미만, 아이콘 65px 미만, 주인공 형태 378px 미만.
- 검정과 흰색 바로 붙이기 컷. 페이드만으로 등장.
- 마지막 60프레임에 글자가 움직이는 것. 390–450의 카메라 푸시.

## 검사 프레임

40, 60, 100, 150, 200, 260, 320, 360, 400, 449 (스틸 10장). 장면마다 하나 이상 포함.
