# route-story: 주문 한 건의 길

목적: 주문이 들어와 문 앞에 도착할 때까지 한 건의 여정을 지도 위 선으로 보여 준다.

형식: 1920×1080, 30fps, 600프레임(20초). 한국어 화면 문구만 쓴다.

가상 브랜드: "나루배송". 실제 회사, 제품, 로고와 무관하다. 화면의 숫자(주문번호 A-0427, 14:20)는 "예시" 또는 "샘플 데이터"로 표기한다.

색(네 개): 잉크 #1C1917, 종이 #FFFBEB, 강조 #EA580C, 연한 주황 #FED7AA. 길이 연한 색에서 강조 색으로 데워지는 부분은 `interpolateColors`가 만드는 중간색이며, 이 한 곳만 예외다.

글꼴: 디스플레이 Jua(헤드라인, 숫자), UI Noto Sans KR(라벨). 두 패밀리 모두 Google Fonts. 이 작품의 글꼴은 `docs/samples/plan.md`에 할당 행이 없어 직접 골랐다. Gothic A1과 #06C755는 쓰지 않는다.

에셋: 수레(스쿠터), 길, 정류 핀, 문은 모두 직접 그린 SVG다. 선 굵기는 18px 하나, 모서리 반지름은 12px 하나. 아이콘 라이브러리는 쓰지 않는다.

## 소리

- 음악: `audio.json`, warm, 96 BPM(마디 2.5초), 타격 2.5초(75프레임)와 15초(450프레임). 섹션은 마디선에 둔다.
- 효과음은 손으로 놓지 않는다. 수레의 x 값(카드 가족, x축)은 `whoosh`(출발), 정류 핀의 scale(모양 가족)은 `pop`(착지), 문의 progress(와이프)는 `ding`(등장)으로 `MotionSound`가 파생한다. 타격 75와 450 근처는 비운다.
- 음량은 0.6 이하, 음악은 0.9.

## 금지

- 실제 지도, 실제 지명, 실제 브랜드 로고.
- 글자 밖으로 번지는 선, 장식 점, 그림자 효과.
- 난수, 시간, 상태(state)에 기대는 움직임. 모든 값은 프레임 함수.
- 마지막 2초(540–600)에 움직임.

## 검사 프레임

20, 60, 110, 180, 260, 340, 410, 450, 500, 570. 각 장면의 주인공이 화면을 채우는지, 글자가 잘리지 않는지, 직전 장과 다른지 본다.
