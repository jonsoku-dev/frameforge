# data-story

목적: 가상의 도시 "솔내시"의 1년 자전거 통행량(샘플 데이터)이 한 숫자에서 열두 막대로, 다시 한 선으로 바뀌며 가장 붐빈 달 하나로 수렴하는 데이터 이야기.

"솔내시"는 가상의 도시다. 실제 도시, 기관, 서비스와 관계없다. 화면의 모든 숫자는 `random('trips-<월>')`로 만든 샘플 데이터이며 화면 오른쪽 위에 "샘플 데이터"를 계속 표기한다.

## 형식

1920×1080, 30fps, 20초(600프레임). 컴포지션 ID `DataStory`.

## 색

| 역할 | 값 |
| --- | --- |
| 바탕 1 (paper) | `#F2F4F3` |
| 바탕 2 (soft) | `#D9E8DF` |
| 강조 (accent) | `#2F8F5B` |
| 글자 (ink) | `#15261B` |

그라데이션 없음.

## 글꼴

- 헤드라인: IBM Plex Sans KR 700. 크기 96px(짧은 변의 8.9%).
- 라벨: IBM Plex Mono 500. 월 라벨 38px, "연간 통행" 92px(독 상태 0.42배로 약 39px), 푸터 34px.
- 큰 숫자: 총합 숫자(250px, 독 상태 약 105px)와 최고값 배지(40px)는 IBM Plex Sans KR 700, `tabular-nums`. Plex Mono의 쉼표는 숫자 한 칸 폭이라 쓰지 않는다.

## 데이터

월별 통행량 = 계절 기준값(천 회: 34 38 57 79 96 88 71 76 99 91 58 40) + `random('trips-<i>')`로 ±4,000회, 100회 단위 반올림. 겨울 낮고 봄·가을 높으며 장마철(7월) 꺼지는 모양이라 실제처럼 읽힌다. 정점 달은 코드에서 최댓값으로 계산한다.

## 소리

- 스펙 `audio.json`: calm, 90 bpm, D major, seed 12. 구간 count-up 0-4s (0.25), bars 4-10s (0.55), line 10-15s (0.7), peak 15-18s (0.65), hold 18-20s (0.1). 히트 15.2초.
- 음악 `/audio/generated/data-story/music.wav` 루트, volume 0.9. 효과음은 `/audio/generated/data-story/<이름>.wav` volume 0.8: 프레임 click.wav 140 + 12i (i = 0..11); ding.wav 456.

calm-20은 app-onboarding과 같은 트랙이다. 이 영상은 12프레임 간격의 규칙적인 틱 열두 번과 종 하나로 구분한다.

## 참고

- `examples/samples/cafe-morning/Spot.tsx`: 루트 `useCurrentFrame()` 하나, `span`, `pop`, `push`, `Glyphs` 마스크, 효과음 배선을 그대로 따른다.
- `docs/references/opus-5-5/README.md`: 2–4초마다 일이 바뀐다, 강조색 하나, 글꼴 둘, 숫자는 확인된 것 또는 샘플만. 이 영상은 숫자 → 막대 → 선 → 한 점으로 장면마다 직전 물체에서 다음 물체가 태어나게 짰다.
