# 포근빵 아이덴트

가상의 동네 베이커리 주문 앱 `포근빵`이 갓 구운 빵을 가장 짧은 주문 흐름으로 연결한다는 점을 알리는 10초 모션그래픽 아이덴트다. 아침에 빠르게 주문하려는 한국어 사용자에게 보여 준다.

- 형식: 1920×1080, 30fps, 300프레임, 10초. 컴포지션 id `PluginSmokeClaude`, 포트 4323.
- 색: 크림 `#FFF6E8`(배경), 잉크 `#2B1D16`(글자), 살구 `#F29B5B`(강조), 버터 `#FFD77A`(보조). 네 가지 이하.
- 글꼴: Black Han Sans(디스플레이), Noto Sans KR(UI).
- 브랜드: 포근빵은 가상의 베이커리 앱이며 화면의 주문 정보는 모두 예시다. 실제 회사, 로고, 제품과 관계없다.
- 에셋: `@/assets`의 Cup, Bag, Bell만 쓴다. 아이콘 라이브러리와 인라인 도형은 쓰지 않는다.
- 참고: 따뜻한 종이색 위에 큰 모티프 하나를 두고, 모티프가 쇼핑백과 벨로 이어지는 단일 모티프 전환. 실제 브랜드는 참고하지 않았다.
- 금지: 인라인 도형, 아이콘 라이브러리, 실제 브랜드, 가짜 휴대폰, 글로우, 파티클, 프레임 테두리.
- 크기(짧은 변 1080 기준): 헤드라인 150px, 라벨 46px, 주인공 모티프 420px 이상(장면 1–3은 540–600px, 마지막 장면은 420px 컵과 200px 글자).

## 장면표

| 프레임 | 시간 | 화면을 채우는 것 | 움직임 | 글자 |
| --- | --- | --- | --- | --- |
| 0–74 | 0–2.5초 | 560px 컵 | 컵이 그려지고 살짝 튀어나온다 | `갓 구운 아침` |
| 75–149 | 2.5–5초 | 600px 쇼핑백(살구 배경) | 살구 면이 왼쪽에서 와이프로 덮이고, 쇼핑백이 왼쪽에서 들어온다 | `한 번에 담고` |
| 150–224 | 5–7.5초 | 540px 벨 | 벨이 위에서 떨어져 닿고 한 번 튕긴다 | `주문이 도착` |
| 225–299 | 7.5–10초 | 420px 컵과 `포근빵` 마크 | 마크가 스프링으로 들어온 뒤 멈춘다. 마지막 60프레임은 움직이지 않는다 | `포근빵`, `갓 구운 하루를 주문하세요` |

"화면을 채우는 것"은 그 행에서 화면 대부분을 덮는 물체다. 배경만 있는 행은 없다.

## 소리

- 음악: `/audio/generated/plugin-smoke-claude/music.wav`, 음량 0.9. 96 BPM이라 한 마디는 2.5초이고, 장면 전환(2.5, 5, 7.5초)이 마디선에 놓인다.
- `audio.json`의 `hits`는 2.5, 5.0, 7.5초(75, 150, 225프레임)에 둔다. 장면이 바뀌는 순간과 같다.
- 효과음은 움직임에서 나온다. `MotionSound`가 움직임 프로브를 따라 낸다. 렌더 로그 기준 실제 위치: `ding` 4프레임(컵이 나타남), `whoosh` 100프레임(쇼핑백 슬라이드 시작), `whoosh` 170프레임(벨 떨어짐 시작), `pop` 202프레임(벨이 닿음). 음악 히트 프레임 75, 150, 225는 `quiet`로 비워 두었다.
- 손으로 놓은 효과음은 없다.

## 검사 프레임

0, 40, 90, 120, 160, 200, 240, 270, 299. 각 프레임에서 모티프나 헤드라인이 화면을 채우고, 글자가 잘리지 않으며, 240프레임 이후 세 프레임이 같아야 한다.
기준 명령: `npm run frame-check -- renders/samples/plugin-smoke-claude.mp4`는 PASS여야 한다.
