# 빵결 앱 아이덴트

가상의 동네 베이커리 주문 앱 `빵결`이 갓 구운 빵을 가장 쉬운 주문 흐름으로 연결한다는 점을 알리는 10초 모션그래픽 아이덴트다. 아침 주문을 빠르게 결정하려는 한국어 사용자에게 보여 준다.

- 형식: 1920×1080, 30fps, 300프레임, 10초.
- 색: 잉크 `#2B1D16`, 크림 `#FFF6E8`, 살구 `#F29B5B`, 버터 `#FFD77A`.
- 글꼴: Black Han Sans(디스플레이), Noto Sans KR(UI).
- 브랜드: 빵결은 가상의 베이커리 앱이며 화면의 모든 주문 정보는 예시다.
- 참고: 따뜻한 종이 위에 큰 한 가지 모티프를 두는 편집 디자인의 여백과, 컵에서 쇼핑백으로 이어지는 단일 모티프 전환을 참고했다. 실제 브랜드나 로고는 사용하지 않는다.
- 금지: 인라인 도형, 아이콘 라이브러리, 실제 브랜드, 가짜 휴대폰, 글로우, 파티클, 프레임 테두리.

| 프레임 | 시간 | 화면을 채우는 것 | 장면 |
| --- | --- | --- | --- |
| 0–74 | 0–2.5초 | 560px 모티프 키트 컵 | 컵이 그려지며 `오늘의 갓구움`이 한 글자씩 올라온다. |
| 75–149 | 2.5–5초 | 600px 모티프 키트 쇼핑백 | 컵의 살구색 화면이 쇼핑백 장면으로 와이프되고 `한 번에 담고`가 나타난다. |
| 150–224 | 5–7.5초 | 540px 모티프 키트 벨 | 쇼핑백의 이동이 벨 도착으로 이어지고 `문 앞에 딩`이 나타난다. |
| 225–299 | 7.5–10초 | 500px 모티프 키트 컵 | 컵이 브랜드 마크처럼 정착하고 `빵결`과 `갓 구운 하루를 주문하세요`를 2초 동안 고정한다. |

오디오는 0–2.5초에 낮게 시작해 2.5초와 5초의 전환에서 음악 히트를 둔다. 컵과 쇼핑백 이동은 whoosh, 각 모티프의 착지는 pop, 벨의 등장에는 ding을 모션 프로브로 연결한다. 마지막 2초는 에너지 0.15 이하로 감쇠한다.

검사 프레임: 0, 45, 75, 120, 150, 195, 225, 270, 299. 각 프레임에서 큰 모티프나 헤드라인이 화면을 채우고, 마지막 60프레임에는 텍스트와 마크가 움직이지 않아야 한다.
