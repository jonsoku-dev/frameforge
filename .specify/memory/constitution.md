# Frameforge Constitution

## Core Principles
### I. Independent MIT implementation
Do not read/copy Remotion implementation or add its runtime dependencies. Follow CONTRIBUTING.md independent implementation rules.
### II. Preserve behavior and user work
Keep public API, successful render pixels, audio and safety restrictions unchanged unless the bounded specification explicitly changes them. Preserve unrelated branches/assets and normal hooks. Do not merge rejected production artifacts.
### III. Evidence before completion
Run repository-required type, test, benchmark and build gates. Renderer changes require a real before/after short render comparison. Report environment-blocked gates honestly; do not claim mocks establish render parity.
### IV. Minimal authorized scope
Implement one bounded requirement-driven change. No security bypass, CI execution, paid services or unrelated cleanup. Generated media stays ignored.

## Development Workflow
Use installed Spec Kit definitions/templates. Commit prospective planning before code for newly specified work. Small unchanged-spec repairs reuse committed authority. Keep acceptance evidence tied to exact source.

## Governance
Existing AGENTS.md and CONTRIBUTING.md remain authoritative repository rules. Amend this document only for agreed project constraints, with semantic version and date changes.
