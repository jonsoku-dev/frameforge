# YouMind, Opus 5.5 프롬프트 목록

주소: https://youmind.com/ko-KR/opus-5-5-prompts

같은 주소가 요청에 두 번 있었다. 페이지는 하나다.

## 읽은 범위

한국어 목록 페이지다. 개별 프롬프트 본문, 영상 파일, 작가별 전문은 이 페이지에 없었다. 카탈로그라고 보는 것이 맞다.

페이지가 말하는 범위는 텍스트 애니메이션, 제품 데모, 설명 영상, 추상 모션이다. 출처는 공개된 X 포스트이고, 작가 요청 시 내린다고 적혀 있다. 사용법은 프롬프트를 고치고, 필요하면 참고 이미지를 붙인 뒤, 브라우저에서 재생되는 애니메이션을 만드는 쪽이다. MP4는 별도 녹화나 렌더가 필요하다고 적혀 있다.

목록에 보인 예시 제목은 도시 이미지 한 건, 테슬라 로드스터의 물리 설명 영상 한 건이다. 본문은 말줄임으로 잘려 있었다.

## 이 프로젝트에 해당하는 것

프롬프트 창고로는 이 페이지만으로 부족하다. 문장과 타이밍과 참고 화면을 우리가 정해야 한다. 재생은 브라우저, 파일은 별도 렌더라는 구분은 Frameforge의 미리보기와 저장과 같다.
