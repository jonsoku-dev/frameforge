# Charlie Hills, Opus 5.5 Motion Graphics

주소: https://charliehills.substack.com/p/opus-55-motion-graphics

공개일 기준 글 제목은 Opus 5.5 Motion Graphics다. 저자는 한 번의 프롬프트가 아니었다고 적었다. 정확한 상태, 레퍼런스, 여러 번의 수정이 필요했다고 한다.

## 읽은 범위

효과 16개 중 01과 02만 공개다. 03부터 16, HTML 보드, PDF, 수정용 프롬프트는 구독 뒤에 있다. 여기에는 공개된 것만 적는다.

## 보드의 형태

16개 효과가 한 HTML 파일에서 8초 루프로 돈다. 글꼴과 이미지는 파일 안에 넣는다. 타일 하나를 떼어 확대하고, 단어와 두 개의 hex만 바꾼다. 모션과 길이는 유지한다.

## 공개된 두 효과

01 Button → player. 미리보기 버튼이 커지며 영상 플레이어가 된다. 데모 숫자라고 밝히고, 글꼴은 임베드한다.

02 Search → results. 검색창에 글자가 써지고 결과가 쌓인다. 공개 예시는 spring campaign이다.

## 이 프로젝트에 해당하는 것

버튼이 화면으로 커지는 변환, 검색이 결과로 이어지는 변환은 한 물체가 다음 장면의 재료가 되는 방식이다. 장면을 잘라 전혀 다른 그래픽을 붙이는 방식과 구분한다.

구독 뒤에 있는 14개 효과의 이름과 프롬프트는 이 문서에 없다.
