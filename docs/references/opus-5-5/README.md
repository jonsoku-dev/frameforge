Frameforge에 바로 쓰는 규칙은 아래 다섯 줄이다.

1. 한 프레임은 시간의 함수다. 타이머, CSS transition, 재생 기록에 의존하는 상태는 쓰지 않는다.
2. 2–4초마다 화면의 일이 바뀐다. 가운데 제목과 그라데이션, 아무 곳이나 파티클, 모든 요소의 바운스는 기본값으로 금지다.
3. 글꼴은 디스플레이 하나, UI 하나. 강조색은 하나.
4. 제품 화면은 상상으로 다시 그리지 않는다. 로고, 색, 숫자, 문장은 확인된 것만 쓴다.
5. 전체 렌더 전에 비트마다 한 장씩 보고, 훅, 휴대폰 가독성, 모션, 다양성, 브랜드, 소리 중 가장 나쁜 세 가지를 고친다.
