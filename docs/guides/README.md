# 가이드

이 폴더는 frameforge로 영상을 기획하고 만들고 검수하는 방법을 모은다. 규칙 원문은 `docs/samples/rules.md`이고, 가이드는 그 규칙을 어떻게 쓰는지 설명한다.

## 읽는 순서

1. `motion-graphics.md`. 모션 그래픽 스팟 작성법. 목적 한 문장, 코드보다 먼저 쓰는 기획서, 화면과 모션 언어, 글자 잘림 가드, 자기 검사 루프를 다룬다. 처음 읽는다.
2. `assets.md`. 에셋 규칙. 오디오, 아이콘, 글꼴, 제품 화면 캡처, 색, 작품별 에셋 명세 양식을 다룬다.
3. `product-explainer.md`. 제품 화면으로 만드는 설명 영상. 화면 확보, 개인정보와 권리, 콜아웃, 카메라, 30초 장면 구조를 다룬다.
4. `model-playbook.md`. 어떤 모델에게 무엇을 맡기고, 모델 수준에 따라 브리프를 어떻게 달리 쓰고, `frame-check`와 교차 리뷰로 어떻게 거르는지 다룬다. 에이전트에게 작업을 맡기기 전에 읽는다.

직접 만들 사람은 1–3을 읽는다. 에이전트에게 맡길 사람은 4도 읽는다.

## 함께 보는 파일

- `docs/samples/rules.md`. 구성 최소치와 검사 기준.
- `examples/samples/_template/`. 새 샘플의 시작점.
- `scripts/frame-check.mjs`. 빈 화면, 정지, 몰림, 작은 요소를 재는 검사.
- `docs/samples/README.md`. 샘플 결과표와, 처음 열 편의 교차 리뷰 결과.
