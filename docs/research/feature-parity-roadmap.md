# 기준 엔진 전 기능 흡수와 레퍼런스 강화 로드맵 (2026-10-20)

사용자 요구: 기준 엔진(Remotion 4.0.537)의 모든 기능을 빠짐없이 Frameforge에 들이고, 다른 레퍼런스(HyperFrames, Motion Canvas, Revideo, MotionForge)로 그 위를 더 강화한다. 이 문서는 전수 목록, 현재 상태, 법적 경계에 따른 흡수 방법, 단계별 계획이다. 법적 경계는 `docs/legal/remotion-license-review.md`가 정한다: 공개 문서, 공개 타입 선언(`.d.ts`), npm 패키지의 블랙박스 실행 기록, JavaScript 산출물의 REA 인벤토리까지만 쓰고, 기준 엔진 라이선스 아래의 구현 코드는 읽거나 옮기지 않는다. MIT 패키지도 같은 방식으로 독립 구현한다(코드를 옮기면 저작권 고지를 함께 실어야 하고, 사용자는 제품에 기준 엔진 이름이 남는 것을 원하지 않는다).

이 표는 착수 시점(2026-10-20 오전)의 상태다. 지금은 "없음, 작음" 17개가 A 단계로, `Video`/`OffthreadVideo`와 "없음, 큼"은 B·F 단계로 들어왔고 `Internals`(비공개 API)만 없다.

`Easing`은 클래스 정적 메서드라 키가 비지만 문서 기준 `linear step0 step1 ease quad cubic poly sin circle exp elastic back bounce bezier in out inOut`이 전부이며 Frameforge는 이미 같은 이름을 갖는다(`compatibility-benchmark.json`으로 수치 검증됨).
